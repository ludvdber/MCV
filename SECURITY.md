# Security Policy

## Supported Versions

Only the latest production version of MCV is currently supported with security updates.

| Version | Supported |
|---------|-----------|
| Latest production version | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature whenever possible.

Please include:

- affected version
- vulnerability description
- steps to reproduce
- potential security impact
- relevant logs or screenshots

Security reports will be investigated before public disclosure.
